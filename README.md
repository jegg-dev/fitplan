# FitPlan

FitPlan is a native SwiftUI iPhone app for building flexible training rotations that combine strength and cardio work.

## Current features

- Create and delete named training splits.
- Add, rename, reorder, and delete days in a split.
- Add strength or cardio exercises to each day.
- Record sets/reps for strength work and duration/intensity for cardio.
- Reorder and delete exercises.
- Automatically save all data on the device.

## Run the app

Open `FitPlan.xcodeproj` in Xcode, select an iPhone simulator, and run the `FitPlan` scheme. The project targets iOS 17 or newer and has no third-party dependencies.
